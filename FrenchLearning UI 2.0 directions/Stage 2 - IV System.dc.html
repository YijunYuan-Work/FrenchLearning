Rule: French is always set in Newsreader, UI chrome in Instrument Sans. Chinese swaps the font family only, never the size, and loosens line-height (+.1). Don't use letter-spacing or uppercase on CJK labels. Numerals and roman numerals use Newsreader; prefer italic for counters ("/ 3").

vi.Accessibility
Keyboard · Study: Space flip, ←/→ move, 1–4 confidence (phrase/grammar). Quiz: Enter checks, focus moves to Next word, Enter continues. All rows and pills are real buttons/radios.
Flip · hidden face gets aria-hidden + inert (already in ReviewView); keep it.
Language · wrap French in lang="fr" so screen readers and hyphenation behave; sidebar glosses are aria-hidden.
Targets · 44px minimum, 52px for mobile action bars. Focus ring always visible (river, 2px).
Live regions · progress counts aria-live="polite"; save status/alert as noted.
vii.Implementation notes
Tailwind · replace frenchBlue/sky/mint/blush in tailwind.config.js with paper, sheet, sheetBright, sky, ink, ink2, mute, river, wood, sage, rule, ruleStrong; add fontFamily.serif = Newsreader, "Noto Serif SC", sans = "Instrument Sans", "Noto Sans SC"; motion tokens in transitionTimingFunction.
Fonts · self-host Newsreader (400/500 + italics) and Instrument Sans (400–600); load SC fonts with unicode-range so EN users don't pay for them.
No logic changes · all states map to existing flags (isDone/isReady, isFlipped, isStudyComplete, isSavingAnswer, answerSaveError, pendingAnswer, lastResult).
